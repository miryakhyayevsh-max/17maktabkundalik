# 17maktabkundalik — серверный MVP

Адаптивное веб-приложение для электронного дневника школы №17. Это серверное приложение Flask с базой данных SQLAlchemy; оно не является автономным HTML-файлом.

## Возможности текущей версии
- вход и выход, хеширование паролей, обязательная смена временного пароля;
- роли: главный администратор, заместитель директора, директор, учитель, классный руководитель, ученик, родитель, психолог;
- создание пользователей, классов и предметов администраторами;
- журнал оценок по шкале 1–10, домашние задания, расписание, посещаемость (Н/О/Б/П), объявления;
- адаптивный интерфейс для телефона.

**Важно:** это рабочая стартовая версия (MVP), а не готовая к эксплуатации школьная система. Пока нет привязки родителя к нескольким детям, разграничения учителя по назначенным классам/предметам, файловых вложений, импорта/экспорта, СОР/СОЧ-аналитики и полноценного аудита. Не загружайте реальные данные учеников до настройки постоянной базы, резервного копирования и проверки безопасности.

## Запуск локально
1. `pip install -r requirements.txt`
2. Задайте переменные `ADMIN_USERNAME` и `ADMIN_PASSWORD` (пароль не менее 10 символов), `SECRET_KEY`.
3. `flask --app app create-admin`
4. `gunicorn app:app`

## Render
1. Загрузите содержимое репозитория в GitHub.
2. В Render выберите New → Blueprint и подключите этот репозиторий.
3. Укажите переменные окружения `DATABASE_URL`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`. `DATABASE_URL` должен указывать на PostgreSQL.
4. После первого запуска таблицы создаются автоматически.

На бесплатном Render веб-сервис может засыпать, а доступность и сохранность PostgreSQL зависят от выбранного тарифа/провайдера. Бесплатную временную БД нельзя использовать для школьных данных.
